# MoonCAS

Pure-MoonBit content-addressed storage kernel with SHA-256 identity,
deduplication, integrity checks, chunked blobs, reference tracking, and garbage
collection.

```bash
moon test --deny-warn
moon run cmd/main
```

See [the type-checked guide](README.mbt.md) for API examples and scope, and
[the Chinese hackathon plan](PROJECT_PLAN.md) for milestones, risks, and
acceptance criteria.
